# MD 檢視器

VS Code 擴充：Markdown 檔點開就是排版好的畫面，不先看到原始碼。每個檔各占一個分頁，想並排就並排。

## 三種狀態

畫面右上角一組三顆鈕：

| 狀態 | 做什麼 |
|---|---|
| 預覽鎖住（預設） | 只看。連結能點、畫面能捲，怎麼點都改不到字。每次打開都回到這個狀態。 |
| 預覽編輯 | 滑鼠移到段落上會出現細框，點下去直接在原地打字。點別處、按 Enter 或 Esc 就定住並寫進檔案。 |
| 原始碼編輯 | 換成 VS Code 一般的文字編輯器，捲到同一個位置。分頁標題列有一顆眼睛圖示可以回到檢視器。 |

預覽編輯能改：一般段落、各級標題、條列項的文字、表格的每一格、引言裡的文字、待辦勾選框。
不能改（請切到原始碼）：程式碼區塊、原始 HTML、圖片、檔案開頭的設定區、表格的加減欄列、新增或刪除整段。

## 寫檔的規則

- **沒碰的段落，檔案裡一個字都不動。** 改了哪一段，就只重寫那一段的那幾行。
- 改的那一段，一般文字寫回去就是你打的字；粗體寫成 `**粗體**`、斜體 `*斜體*`、連結 `[字](網址)`、刪除線 `~~字~~`。不會替你加反斜線。
- 段落裡按 Shift+Enter 是硬換行（行尾兩個空白）；標題與表格格子不能換行。
- 預設改完就自動存檔（設定 `mdview.autoSave`）。

## 設定

| 設定 | 預設 | 說明 |
|---|---|---|
| `mdview.autoSave` | `true` | 改完一段就直接寫進檔案 |
| `mdview.fontSize` | `15` | 字級（px） |
| `mdview.maxWidth` | `980` | 內文最大寬度（px），0 代表填滿分頁 |

想讓某個檔用一般文字編輯器開：分頁上按右鍵「Reopen Editor With…」。想整個改回預設：設定 `workbench.editorAssociations` 把 `*.md` 指到 `default`。

## 安裝與打包

```
powershell -ExecutionPolicy Bypass -File build.ps1
code --install-extension mdview-<版號>.vsix --force
```

打包前會先跑 `node test/edit-core-test.js` 與語法檢查，沒過不打包。

## 內部結構

| 檔案 | 角色 |
|---|---|
| `extension.js` | 自訂編輯器的主程式：開分頁、送內容、把畫面回傳的「第幾行換成什麼」寫進檔案、開連結、切原始碼 |
| `media/view.js` | 畫面端：markdown-it 畫畫面、三態鈕、就地編輯、turndown 把改過的那一格轉回 markdown |
| `media/edit-core.js` | 改字的純邏輯（前綴、表格格子、待辦、設定區），畫面端與測試共用 |
| `media/view.css` | 樣式，顏色全走 VS Code 主題變數 |
| `media/markdown-it.min.js`、`media/turndown.js` | 第三方程式庫（MIT） |
| `test/edit-core-test.js` | 純邏輯測試 |
