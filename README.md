# MD 檢視器

在 VS Code 裡點開 Markdown 檔，看到的就是排好版的文章，不是一堆井字號和星號。
想改幾個字，按右上角的鉛筆，點那一段就能打字。改完會自動存檔。你沒改的段落，檔案裡一字不變。

## 安裝

1. 到這個專案的 Releases 頁下載 `mdview-版號.vsix`。
2. 在 VS Code 左側點「擴充功能」，按清單上方的「…」，選「從 VSIX 安裝」（Install from VSIX），挑剛下載的檔。
3. 按 Ctrl+Shift+P，輸入「Reload Window」，按 Enter。

更新時用新的檔再做一次。裝好之後，所有 `.md` 檔都會用這個畫面打開。

## 你會看到什麼

點開任何 `.md` 檔，分頁裡直接是標題、段落、表格、條列的樣子。
想同時看兩份，把分頁拖到旁邊就是並排，要開幾個都可以。

畫面右上角有三顆按鈕，分別切換三種狀態：只看、在畫面上改字、改 Markdown 原文。滑鼠停在按鈕上會顯示名稱。

| 按鈕 | 名稱 | 用途與畫面 |
|---|---|---|
| 鎖頭 | 預覽鎖住 | 只看，不會改到字。連結可以點。每次打開檔案都是這個狀態。 |
| 鉛筆 | 預覽編輯 | 改幾個字。滑鼠移到段落上，能改的會出現細框。點一下就能打字。 |
| 角括號 | 原始碼編輯 | 改畫面上改不到的地方，例如加一列表格、新增一整段。畫面會換成 Markdown 原文，也就是帶井字號和星號的文字。 |

不管在哪個狀態，三顆按鈕都在，按哪一顆就切到哪個狀態。

## 改字

1. 按右上角的鉛筆。鉛筆會變亮。
2. 點你要改的那一段，游標會出現在那一段裡。
3. 打字修改。
4. 改完按 Enter，或點那一段以外的地方。修改會自動存進檔案。

段落裡要換行，按 Shift+Enter。標題和表格的格子不能換行。

能這樣改的：一般段落、各級標題、條列的文字、表格的每一格、引言裡的文字、待辦的勾選框（點一下就勾）。

以下要按角括號，改 Markdown 原文：程式碼、檔案最上方灰底的設定文字、圖片、表格加減欄或列、新增或刪除整段。
滑鼠移到這些地方，會看到「這一塊要改請切到原始碼」。

## 設定

按 Ctrl+, 打開設定，搜尋「mdview」，就能改下面三項。

| 項目 | 預設 | 說明 |
|---|---|---|
| 改完自動存檔（autoSave） | 開 | 關掉的話，改完要自己按 Ctrl+S |
| 別的程式開的 md 也換成檢視器（takeOver） | 開 | 例如在 Claude Code 對話裡點 md 連結。關掉的話，那些會照原本的方式用文字編輯器開 |
| 字級（fontSize） | 15 | 單位是 px |
| 內文最大寬度（maxWidth） | 980 | 單位是 px，填 0 就佔滿整個分頁 |

## 常見問題

**我想用 VS Code 原本的文字編輯器開這個檔。**
按 Ctrl+Shift+P，輸入「改用 VS Code 文字編輯器開這個檔」，按 Enter。
要回來時，按分頁右上方的眼睛圖示（回到 MD 檢視器）。

**我想讓所有 md 檔都回到原本的開法。**
在任一個 md 檔的分頁上按右鍵，選「Reopen Editor With…」，再選「設定 '*.md' 的預設編輯器」（Configure default editor），挑「文字編輯器」。

**在 Claude Code 的對話裡點 md 連結，開出來是原始碼。**
裝 0.3.0 以上就不會。對話面板開檔時不看「預設編輯器」的設定，檢視器會在它開出文字編輯器的瞬間接手換成預覽，並停在連結指的那一行。

**我在改的時候，別的程式也改了同一個檔。**
畫面會換成另一個程式存的最新內容。你剛才沒存進去的那一段會被捨棄，檔案不會壞。

## 給開發者

### 它怎麼寫檔

- 預覽編輯只重寫使用者改的那一段：訊息是「第 from 行到第 to 行換成 text」，其他行不經手。
- 原始碼編輯送整份文字，版本號對得上才寫。
- 轉回 Markdown 時不加反斜線；粗體 `**粗體**`、斜體 `*斜體*`、連結 `[文字](網址)`、刪除線 `~~文字~~`、硬換行是行尾兩個空白。

### 打包與安裝

```
powershell -ExecutionPolicy Bypass -File build.ps1
code --install-extension mdview-<版號>.vsix --force
```

打包前會自動跑 `node test/run-all.js` 與 `node --check`，沒過不產生檔案。
轉回 Markdown 的測試需要 node 版 turndown，把它的資料夾路徑放在環境變數 `MDVIEW_TURNDOWN`；沒有就略過那支。
新增檔案要加進 `build.ps1` 的白名單，不然裝了會缺檔。

想用設定檔切回預設編輯器：`workbench.editorAssociations` 把 `*.md` 指到 `default`。

### 檔案

| 檔案 | 角色 |
|---|---|
| `extension.js` | 自訂編輯器主程式：開分頁、送內容、把畫面回傳的改動寫進檔案、開連結 |
| `media/view.js` | 畫面端：三顆按鈕、就地編輯、原始碼文字框、與主程式的通道 |
| `media/render-core.js` | markdown-it 的設定：每個區塊帶起訖行、標記可改與不可改（純邏輯，有測試） |
| `media/turndown-rules.js` | 改過的那一格 HTML 轉回 Markdown 的規則（純邏輯，有測試） |
| `media/edit-core.js` | 前綴保留、表格格子替換、待辦切換、設定區偵測（純邏輯，有測試） |
| `media/view.css` | 樣式，顏色全走 VS Code 主題變數 |
| `media/markdown-it.min.js`、`media/turndown.js` | 第三方程式庫（MIT） |
| `test/` | `node test/run-all.js` 跑全部 |

## 版本紀錄

### 0.3.0（2026-10-22）
- 別的程式用文字編輯器開 md 檔時（例如 Claude Code 對話裡的連結），自動換成檢視器並停在同一行。
  你自己選文字編輯器的不會被換。可在設定關掉（takeOver）。

### 0.2.0（2026-10-21）
- 原始碼編輯在同一個分頁裡進行，三顆按鈕一直都在。
- 切換狀態時兩邊停在同一行。
- 畫面可以用 Ctrl+F 搜尋。

### 0.1.0（2026-10-21）
第一版：md 檔點開就是排好版的畫面；三種狀態；可以直接在畫面上改段落、標題、表格格子、待辦勾選；改完自動存檔。
